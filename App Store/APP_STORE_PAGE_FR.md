# Page App Store — Amor&Contas (Français)

## Nom de l’app
Amor&Contas

## Sous-titre
Répartissez les dépenses du couple avec équité

## Description courte
Amor&Contas aide les couples à partager leurs dépenses de manière simple, transparente et équilibrée, avec un mode 50/50 ou proportionnel.

## Description détaillée
Amor&Contas a été conçu pour faciliter les conversations d’argent au quotidien dans le couple.

Avec une interface claire et directe, vous enregistrez les dépenses, suivez ce que chacun a payé et obtenez automatiquement une suggestion de règlement.

Deux modes de répartition sont disponibles :

- **50/50** : idéal pour partager à parts égales, sans tenir compte des revenus.
- **Automatique (Échelle)** : idéal pour une répartition proportionnelle. En utilisant le revenu net comme échelle, l’effort financier tend à rester équilibré pour les deux.

### Fonctionnalités principales
- Saisie rapide des dépenses par personne.
- Calcul automatique de la part équitable.
- Message de règlement prêt à partager.
- Paramètre de symbole de devise.
- Paramètre du mode de répartition (50/50 ou proportionnel).
- Section explicative “À propos” dans l’app.
