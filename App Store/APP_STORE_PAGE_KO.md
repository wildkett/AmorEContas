# App Store 페이지 — AmorEContas (한국어)

## 앱 이름
AmorEContas

## 부제
커플 지출을 공정하게 분담하세요

## 짧은 설명
AmorEContas는 커플이 지출을 쉽고 투명하며 균형 있게 나눌 수 있도록 도와줍니다. 50/50 또는 스케일 기반 비율 분담을 지원합니다.

## 상세 설명
AmorEContas는 커플의 일상적인 돈 관련 대화를 더 쉽게 만들기 위해 만들어졌습니다.

직관적인 인터페이스로 지출을 기록하고, 각자가 얼마나 지불했는지 확인하며, 자동으로 정산 제안을 받을 수 있습니다.

분담 방식은 2가지입니다.

- **50/50**: 소득 차이와 상관없이 동일하게 나누고 싶을 때 적합합니다.
- **자동(스케일)**: 비율에 따라 나누고 싶을 때 적합합니다. 각자의 순소득을 스케일 값으로 사용하면 부담 균형을 맞추기 쉽습니다.

### 주요 기능
- 사람별 빠른 지출 등록.
- 공정 분담 자동 계산.
- 바로 공유 가능한 정산 메시지.
- 통화 기호 설정.
- 분담 방식 설정(50/50 또는 비율).
- 앱 내 사용 가이드(About).
